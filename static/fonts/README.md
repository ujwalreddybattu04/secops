# Workspace typography

Inter Variable is self-hosted so the analyst workspace needs no external font
request. The unmodified `InterVariable.woff2` was downloaded from the official
distribution at https://rsms.me/inter/font-files/InterVariable.woff2.

Source project: https://github.com/rsms/inter

The font is distributed under the SIL Open Font License 1.1. Keep `LICENSE.txt`
alongside the font when redistributing this application. System fonts remain
the fallback for unavailable glyphs and while the font loads. The PDF's existing
Unicode font is unchanged.
